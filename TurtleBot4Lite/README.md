# Estudo do TurtleBot 4

## Objetivo

Esta seção reúne os estudos realizados sobre o TurtleBot 4, utilizado como plataforma de referência para compreender a integração entre hardware e software em robótica móvel.
O estudo tem como finalidade analisar a arquitetura de um robô móvel real e compreender como diferentes componentes: sensores, computador embarcado, sistema de locomoção e alimentação são integrados utilizando ROS 2.
O TurtleBot 4 não constitui o objetivo final deste repositório, mas uma plataforma de referência para o aprendizado e desenvolvimento de conhecimentos aplicados posteriormente ao projeto de um robô próprio.

---

## Componentes estudados

* Raspberry Pi 4
* RPLIDAR A1M8
* OAK-D-Lite
* iRobot Create 3
* Sistema de alimentação
* Sistema de carregamento

## Conceitos estudados

Durante a análise do TurtleBot 4 serão estudados:

* Comunicação entre sensores e computador;
* Aquisição de dados;
* Odometria;
* Sensores de distância;
* Visão computacional;
* ROS 2;
* Localização;
* Mapeamento;
* SLAM;
* Navegação autônoma;

## Relação com o projeto próprio

O conhecimento adquirido através do estudo do TurtleBot 4 será utilizado como referência para decisões relacionadas ao desenvolvimento de uma plataforma robótica própria.

Entre os aspectos a serem aproveitados estão:

* Arquitetura de hardware;
* Seleção de sensores;
* Integração com ROS 2;
* Alimentação;
* Localização e mapeamento;
* Navegação autônoma.
